# StickMan Studio

This AI Powered visual video creator.It creates video explanation of anything majorly coding concepts and problems

## Goal

Create educational coding videos using:

- AI-generated explanations
- 2D stick-man characters
- DSA visualizations
- Real code
- Text-to-speech
- Subtitles
- Sound effects
- Video rendering

## Characters

- Midoriya — Teacher
- Bakugo — Student

## Video Formats

- YouTube: 1920×1080, 16:9
- Short-form: 1080×1920, 9:16
